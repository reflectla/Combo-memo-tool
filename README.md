# Combo Memo Tool (格闘ゲームコンボメモ補助ツール)

格闘ゲームのコンボメモ作成を支援するためのツールです。コンボ構成を視覚的に組み立てることができ、テキスト出力や画像形式（コンボカード）での保存に対応しています。
ブラウザだけで動作し、会員登録やインストールは不要です。

## 主な機能

### 1. キャラクタープロファイル管理
- **自由なカスタマイズ**: ゲーム名、キャラクター名、アイコンを自由に設定。
- **リソース（ゲージ）定義**: ドライブゲージ、SAゲージ、バーストなど、ゲーム独自のゲージを定義可能。
    - 消費量、獲得量、必要量の表示設定を細かくカスタマイズできます。

### 2. コンボ入力・編集
- **ビジュアルモード**: ボタンをクリックするだけで、技、接続、修飾子、ヒット数注釈を組み合わせてコンボを作成。
- **テキストモード**: キーボードから直接入力。
    - **正規化機能**: スペースの有無などを自動調整し、表記を統一。
    - **自動接続補完**: 技名を入力すると、設定されたデフォルトの接続タイプを自動補完。
- **ドラッグ＆ドロップ**: 作成したコンボのパーツを後から自由に入れ替え。
- **挿入モード**: 技と技の間の「+」をクリックして、任意の場所に技を割り込ませることができます。

### 3. 高度なタグシステム
- **視覚的な色分け**: 「始動」を含むタグはシアン、その他はオレンジなど、直感的に判別可能。
- **タグによる絞り込み**: ライブラリ内の大量のコンボをタグで素早くフィルタリング。
- **ドラッグ＆ドロップ登録**: 既存のタグをコンボにドラッグするだけで簡単割り当て。

### 4. コンボライブラリ
- **検索・ソート**: 名前、ダメージ、更新日時などで並び替えや検索が可能。
- **一括操作**: 複数のコンボを選択して、テキスト形式での一括出力や一括削除が可能。
- **上書き/別名保存**: 読み込んだコンボを編集して上書き、または新しいコンボとして保存。

### 5. 画像エクスポート
- **コンボカード出力**: 作成したコンボをPNG画像として保存。
- **レイアウト**: キャラクターアイコン、ダメージ、ゲージ使用状況、タグが配置されます。
- **ビジュアル連動**: エディタ上の配色やフォントがそのまま画像に反映。

### 6. データ管理
- **オートセーブ**: ブラウザの `localStorage` により、作業内容は自動的に保存されます。
- **ファイル連携**: 全データをJSONファイルとしてエクスポート/インポート可能。特定のファイルに直接上書き保存する機能も備えています。

## 📖 使い方

### 1. 準備する
1. 左上の「キャラクター切替」から新しいキャラクターを作成します。
2. 技パネルの「➕」ボタンから、よく使う技を登録します。
3. **[Tips]** 「📄（一括登録）」ボタンを使うと、技リストをコピー＆ペーストで一気に登録できて便利です。

### 2. コンボを作る
1. 技ボタン、接続ボタン（ > , xx など）、修飾子ボタンをクリックして繋げます。
2. ダメージ、タグ、備考を入力します。
3. ゲージ消費がある場合は、リソースエリアに数値を入力します。

### 3. 保存・管理する
1. 「ライブラリに保存」ボタンで、左側のサイドバーに保存されます。
2. 保存したコンボをクリックすると再編集できます。

### 4. 共有する
1. 「画像で保存」ボタンを押してコンボカードを出力します。
2. SNSやブログ、メモ帳などに貼り付けて活用しましょう！

## 🛠️ 技術仕様・高度なルール

### テキストモードの正規化
テキスト入力時、以下の記号は自動的に整形されます。
- `> ` : 通常接続
- `xx ` : キャンセル
- `(dl)` : ディレイ（修飾子として定義されている場合）
- `(5 hit)` : ヒット数注釈（数値は自由に変更可能）

### 一括登録の書式
「📄（一括登録）」では、以下の形式で技を記述してください。
- `表示名, コマンド`
- `表示名 / コマンド`
- ※区切り文字がない場合は、表示名とコマンドが同じになります。
