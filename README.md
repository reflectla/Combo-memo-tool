# Combo Memo Tool (格闘ゲームコンボメモ補助ツール)

格闘ゲームのコンボを視覚的記録し、画像として出力・共有するためのWebアプリケーションです。

##  主な機能

### 1. キャラクタープロファイル管理
- ゲーム名、キャラクター名、アイコンの設定。
- **リソース（ゲージ）定義**: キャラクターごとに使用するゲージ（例：ドライブゲージ、SAゲージ）を独自に定義可能。
    - 消費（使用量）、獲得量、必要量の表示設定をカスタマイズできます。

### 2. コンボ入力・編集
- **ビジュアルモード**: ボタンをクリックするだけで、技、接続タイプ、修飾子、ヒット数注釈（○hit）を組み合わせてコンボを作成できます。
- **テキストモード**: キーボードから直接コンボを入力可能。
    - **正規化機能**: `> ` や `xx ` といった記号の後のスペースを自動調整。
    - **自動接続**: 技名を入力すると、設定されたデフォルトの接続タイプを自動的に補完します。
- **ドラッグ＆ドロップ**: 作成したコンボのパーツを直感的に入れ替え可能。

### 3. コンボライブラリ
- 作成したコンボを名前、ダメージ、タグ、備考とともに保存。
- 保存したコンボの呼び出し、上書き保存、削除、別名保存に対応。
- フィルター機能（キャラクター別、タグ別）で目的のコンボを素早く検索。

### 4. 画像エクスポート
- 作成したコンボを「コンボカード」として画像（PNG）で保存。
- キャラクターアイコン、ダメージ、リソース使用状況、タグが美しくレイアウトされます。
- **ビジュアル連動**: エディタ上の見た目（配色やフォント）がそのまま画像に反映されます。

### 5. データ永続化・互換性
- ブラウザの `localStorage` を使用し、ページを閉じてもデータが保持されます。
- 全データをJSONファイルとしてエクスポート/インポート可能。

##  使い方

### 最初のステップ
1. 左上の「キャラクター切替」からキャラクターを作成します。
2. その際、「リソース定義」からそのゲームで使用するゲージを追加しておくと便利です。

### コンボの作成
- 下部の技パネルや接続タイプパネルをクリックしてコンボを組み立てます。
- ダメージやタグ、備考、ゲージ使用量を入力します。
- 「ライブラリに保存」を押して記録します。

### 画像の出力
- 「画像で保存」ボタンを押すと、現在のコンボがカード形式でレンダリングされ、ダウンロードされます。
- ※URLでアイコンを指定している場合、外部サイトの制限により画像に含まれないことがあります。その場合は「アップロード」機能で直接画像を保存してください。

##  技術仕様・高度な機能

### テキストモードのルール
テキストモードでは以下の記号が特殊な意味を持ちます。
- `> `: 通常接続
- `xx`: キャンセル
- `(dl)`: ディレイ（修飾子として定義されている場合）
- `(5 hit)`: ヒット数注釈（数値部分は自由に変更可能）

### リソース管理
- コンボごとに「消費（使用量）」「獲得量」「必要量」を数値で管理できます。
- 画像出力時、すべてが空または0のゲージは自動的に非表示になります。
